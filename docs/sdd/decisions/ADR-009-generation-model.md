# Decision Record: ADR-009 생성 모델

> Created at: `2026-10-10`
> ClickUp 작업: 해당 없음: 초기 세팅 단계 예외(WBS 0.9)
> 기능명세서 ID: 해당 없음: Phase 0 준비 작업
> Status: Proposed

## Context

검색된 근거로 답변을 만드는 생성 모델을 정해야 한다. QK-GEN-001(1.10)의 프롬프트와 출처 표시 규칙,
QK-BOT-001(1.11)의 응답 지연이 이 선택에 달려 있다.

조건은 네 가지다. 한국어를 공식 문서에 명시한 모델이어야 한다. 응답이 빨라야 한다. Workers Free 할당
안에서 돌아야 한다. 문맥 속 지시문을 실행하지 않아야 한다(constitution C-03).

WBS 0.6에서 이 조건으로 후보를 좁히고 `@cf/qwen/qwen3-30b-a3b-fp8`(추론 끔), `@cf/ibm-granite/granite-4.0-h-micro`,
`@cf/mistralai/mistral-small-3.1-24b-instruct`를 한국어 질문 5개로 비교했다. Llama 계열(한국어 공식 미지원),
gpt-oss(지원 언어 미명시, 50건이면 할당의 약 89%), gemma-4(한국어 명시 없음)는 호출하지 않았다.

## Decision

생성 모델은 `@cf/qwen/qwen3-30b-a3b-fp8`을 추론을 끈 상태(`/no_think`)로 쓴다.

## Rationale

- 지연이 셋 중 가장 짧고 편차도 가장 작았다. 중앙값 1,015 ms(544~1,125), 평균 957 ms다.
- 품질 항목을 모두 통과했다. 필수 사실 4/4, Source ID 표시 4/4, 확인 불가 응답 정확, 문맥 속 지시문 무시 5/5다.
- 문맥 속 지시문을 5문항 전부 무시했다. mistral-small은 5문항 중 2번 따랐고 이는 C-03 위반 위험이다.
- 비용이 호출당 6.55 Neurons로 둘째로 낮다. 하루 50건이면 무료 할당의 3~8%다.
- 한국어를 공식 문서에 명시한다.

## Alternatives considered

| Alternative | Advantages | Disadvantages | Reason not selected |
| --- | --- | --- | --- |
| `@cf/ibm-granite/granite-4.0-h-micro` | 호출당 2.64 Neurons로 가장 싸다. 지시문을 따르지 않았다(5/5). 컨텍스트 131,000 | 문서 2개를 합치는 질문(G3)에서 FCM 결정을 빠뜨렸다. 지연 중앙값 2,471 ms로 가장 길다. 같은 프롬프트 입력 토큰이 1,233으로 가장 많다. 3B 소형 모델이다 | 종합 질문에서 사실을 빠뜨렸고 지연이 길다 |
| `@cf/mistralai/mistral-small-3.1-24b-instruct` | 필수 사실 4/4. 같은 프롬프트 입력 토큰이 890으로 가장 적다. 컨텍스트 128,000 | **문맥 속 지시문을 5문항 중 2번 따랐다(C-03 위반 위험)**. 호출당 31.69 Neurons로 qwen3의 약 5배다. 문장마다 출처를 단 답변이 0/4 | C-03 위반 위험이 있고 가장 비싸다 |

## Evidence

- `docs/sdd/research/spike-workers-ai.md` 4절·5.2절. 측정 조건: 합성 한국어 문서 12개를 문맥으로 쓴 질문 5개
  (부록 A.3), 모델별 1회 호출(n=5), 2026-10-09, 생성 15회에 쓴 Neurons 약 710.
- 한국어 지원과 `/no_think` 근거는 같은 문서 7절의 모델 카드 출처([M3][M4][M5][M6]).
- 표본이 모델별 5문항 1회다. 품질 항목은 방향만 본다.

## Data and cost

- 외부로 전송되는 데이터와 제공자의 학습 사용·보존 정책: 질문과 검색된 청크 본문을 Cloudflare Workers AI로
  보낸다. Cloudflare는 Workers AI 입력·출력을 모델 학습에 쓰지 않는다고 밝힌다(`spike-workers-ai.md` 7절).
- 무료 한도와 예상 사용량: 하루 10,000 Neurons. 하루 50건 × 6.55 ≈ 330 Neurons로 약 3%다.
  입력 3,000·출력 1,200토큰을 가정한 상한에서도 8% 안이다.
- 교체 시 영향: 생성 모델 교체는 재임베딩이나 인덱스 버전과 무관하다. 프롬프트와 답변 평가 기준선만 다시 잡는다.

## Consequences

### Positive

- 응답 지연이 짧아 Discord 후속 메시지 갱신까지 여유가 있다(NFR-02 비교는 Phase 2에서 측정한다).
- 문맥 속 지시문을 무시해 C-03을 지킨다.

### Negative / risks

- 기본이 추론 모드다. `/no_think`를 붙이지 않으면 지연과 토큰이 늘어난다. QK-GEN-001에서 이 설정을 기본값으로
  고정하고 테스트로 막는다.
- 문장마다 출처를 다는 프롬프트 규칙을 4문항 중 2문항만 지켰다. 출처 표시는 프롬프트와 후처리로 보강해야 한다.
- 컨텍스트가 32,768로 셋 중 가장 짧다. RAG 문맥에는 충분하지만 문맥 확장 상한을 여기에 맞춘다(QK-RET-001).
- 표본이 5문항 1회다. 이 결정은 답변 평가(QK-EVL-002, 2.5)에서 다시 확인한다.

## Revisit conditions

- QK-EVL-002(2.5) 답변 평가에서 충실성·인용 정확도·확인 불가 응답이 목표에 못 미칠 때.
- 하루 질문이 늘어 생성 비용이 무료 할당의 50%를 넘을 때.
- 모델이 Workers AI 카탈로그에서 내려가거나 단가가 오를 때(RISK-04).
- 문맥 속 지시문을 따르는 사례가 운영에서 한 번이라도 관찰될 때.
