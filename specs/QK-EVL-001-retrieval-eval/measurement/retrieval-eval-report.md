### 1.1 ADR-010 판단 규칙

측정 전에 정하고 측정 뒤에 바꾸지 않는다. n·m은 사람이 표본 수를 보고 정했다(H05, 2026-11-04: n = 3, m = 1).

- 후보 B와 C를 각각 A와 비교한다. 비교는 공통 질문 집합으로 하고, 뺀 질문은 사유와 함께 적는다.
- 후보 X는 다음을 모두 만족하면 "권고 가능"이다.
  1. 주 지표: 일부 질문 20문항 가운데 키워드 상위 20건에 든 질문 수가 A보다 **n = 3문항 이상**(20문항 가운데 15%p) 많다.
  2. 가드레일: G1~G5 각각이 A보다 **m = 1문항 넘게** 나빠지지 않는다. G1·G5는 질문 수가 줄어든 만큼, G2·G3은 나빠진 질문 수, G4는 늘어난 질문 수를 센다.
  3. 실행 유효: 1절 성공 기준을 만족한다.
- B와 C가 모두 "권고 가능"이면 주 지표가 더 많이 오른 후보를 권고한다. 같으면 운영 변경이 작은 후보 B(새 인덱스 버전만, 마이그레이션 없음)를 권고한다.
- 어느 후보도 "권고 가능"이 아니면 A(현행 유지)를 권고한다.
- 권고는 작성 세션 의견이고, ADR-010 Status와 운영 반영은 사람이 정한다(QK-RET-001 FR-021). 운영 규칙·토크나이저·`RetrievalSettings`는 이 작업에서 바꾸지 않는다.

## 8. Interpretation

### 8.1 측정 결과

- 세 방식(골든 v2, A): 하이브리드 Recall@5 22/23, MRR 0.7576. 벡터 전용 18/23·0.7738, 키워드 전용 17/23·0.6329. v1 부분 집합 8문항은 하이브리드 8/8.
- 1.1절 규칙(n = 3, m = 1): B는 주 지표 +4로 n을 넘었으나 G4가 +2로 m을 넘었다. C는 주 지표 +5로 n을 넘었으나 G3(5문항)과 G4(+4)가 m을 넘었다.
  두 후보 모두 "권고 가능"이 아니다. 규칙에 따른 권고는 **A(현행 유지)**다.
- 실행은 1절 성공 기준(완료, 비교 조건 같음, Neurons ≤ 예상치, 운영 DB 쓰기 0)을 만족했다. 4절 수치와 다시 센 값의 대조는 T042에서 한다.

### 8.2 작성 세션 해석

- 가설 가운데 "일부 질의를 더 많이 찾는다"는 B·C 모두에서 지지된다(일부 질문 35문항 키워드 Recall@5 A 26 → B 32, C 31). "골든 하이브리드 품질이 나빠지지 않는다"는 B에서 지지되고 C에서는 한 문항(`cand-S31`)이 나빠졌다.
- B가 걸린 G4는 정밀도 대용 지표다. 새로 상한에 닿은 두 질문은 일부 낱말이 흔한 경우(`handler`, `open`)이고, 같은 질문의 첫 근거 순위는 B에서 오히려 좋아졌다(`acronym-01-partial` 7 → 4). B의 G3(실제 Precision@5)은 한 문항만 낮아졌다.
  다만 판단 규칙은 측정 전에 고정했으므로 이 해석으로 권고를 바꾸지 않는다.
- 표본 한계: 주 지표 20문항에서 한 문항은 5%p, 골든 v2 23문항에서 한 문항은 약 4.3%p(v1 부분 집합 8문항은 12.5%p)다. B의 G4 초과는 1문항 차이다.
- B 대상에서만 벡터 전용 상위 20건이 다른 질문이 9개 있다(첫 근거 순위는 같음). B는 동기화로 새로 만든 데이터베이스라 HNSW 근사 색인 그래프가 다른 것으로 보인다. 이 차이는 B와 A의 하이브리드 지표를 바꾸지 않았다.

### 8.3 제안(수치 근거, 결정은 사람)

- Recall@5·MRR 목표 후보(spec FR-028): 골든 v2 하이브리드의 첫 수치(Recall@5 22/23, MRR 0.7576)를 기준선으로 두고, 인덱스 버전 평가 게이트(QK-STO-002)의 회귀 기준 후보로
  "Recall@5 21/23 이상(한 문항 허용), MRR 0.70 이상"을 제안한다. 23문항이라 정밀한 목표가 아니라 회귀 경보로 쓰는 편이 맞다.
- 검색 설정(spec FR-029): 골든 v2 키워드 전용은 23문항 가운데 22문항이 결과 상한(20)에 닿았다. 자연어 질문에서 키워드 일치가 넓다는 뜻이다. 지금 하이브리드 결과는 좋아 기본값 변경은 제안하지 않는다.
  운영 기본값과 키워드 규칙은 바꾸지 않았다.
- 후속 후보(사람 결정): 식별자 일부 질의가 팀 질문에서 실제로 중요한지 확인한 뒤, 판단 규칙을 다시 정해 B를 큰 표본으로 다시 재는 별도 작업.
