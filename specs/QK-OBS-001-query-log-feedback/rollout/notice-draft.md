# H01 Discord 공지 초안

편집자용: **미게시 초안**(2026-11-04). 아래 표시 사이의 본문만 Discord 메시지 한 개로 게시한다. ADR-016 승인과 메모리 대기의 C-10 해석 수용은 2026-11-04 사용자 결정이다. 게시 증빙과 운영 명령별 승인은 아직 없다.

게시 전 확인 목록:

- 운영 배포일·시작일은 2026-11-04, 보존 상한은 2026-12-04(UTC)로 확정했다. 공지·동의 문서·설정에 같은 값을 쓴다. 배포가 2026-11-04를 넘기면 시작일, 상한 날짜, 설정 값을 함께 고치고 게시 전이면 문구를, 게시 후면 정정 공지를 낸다.
- 공지·동의 문서는 배포일 확정 후 배포 전에 게시하고 ADR-016에 기록한다. 그 뒤 0008 적용·기록 꺼짐 배포 등 H02를 진행하고, 같은 운영 배포일에 기록 기능을 켠다.
- 분석 목적의 원문 열람자와 운영 담당자는 GitHub 계정 byuntil, tkv00 두 명으로 같다. 삭제 작업의 관리 연결 접근은 이 열람 범위를 넓히지 않는다. 서버 소유자는 tkv00(사용자 확인)이다. 2026-11-04 확인상 운영 서버의 sudo 또는 docker 그룹 권한으로 원문을 읽을 수 있다. 서버 관리 권한 전체 명단은 미확인이므로 게시 전에 사람이 확인한다. 계정 이름·키 내용·서버 식별 정보는 기록하지 않는다.
- 삭제·문의는 운영 담당자에게 Discord DM으로 받는다. `<운영 담당자 멘션>`의 실제 멘션과 실명은 게시본에서만 치환하고 저장소에 적지 않는다. Confluence 링크도 게시 전에 확정한다.
- Workers AI 정책 확인 완료: 2026-10-16 갱신 공개 문서를 2026-11-04 조회했다. 제공자 공개 문서 기준이며 독립 검증한 보장으로 취급하지 않는다. 게시 직전 같은 페이지를 재확인한다(Source ID CF-DATA).
- 2026-11-04 확인 범위에서 운영 DB 백업은 발견되지 않았다. 다른 컴파트먼트의 수동 백업·이름이 다른 스크립트·서버 밖 복사는 미확인이다. 백업이 생기면(QK-SYN-003, WBS 5.2) 동의 문서를 고치고 다시 공지한다는 방침은 사람 확인 대상이다. 그때 백업 보존 기간·접근 범위·복원 뒤 재삭제 방법도 확정한다.
- 전체 원문 삭제는 메모리 대기를 지우지 못한다. 기능 끄기·재시작으로 대기를 비운 뒤 삭제하거나 대기 종료 후 다시 삭제하는 순서와 기능 유지·재개 여부를 Confluence 문서에서 확인한다.
- ADR-016 승인과 동의 전 메모리 대기의 C-10 해석 수용은 2026-11-04 사용자 결정으로 완료했다. 공지·문서 게시 링크·날짜 기록은 남아 있다. 운영 명령마다 별도 승인을 받는다.
- 본문은 placeholder 상태에서 UTF-16 기준 1,500자 이하로 작성한다. 실제 링크·결정값 치환 후 다시 측정해 2,000자 이하인지 확인한다.

팀 봇 개선을 위해 2026-11-04에 기록 기능을 켜고 질의 기록과 👍·👎 피드백을 수집하려고 합니다. 자세한 내용: <Confluence 동의 문서 링크>

질문자 본인이 자기 질문에 대한 답변의 👎를 누르면 질문 저장 동의를 묻고, [저장 동의]를 선택한 질문 하나만 저장합니다. 기본은 [저장 안 함]이며 👍나 다른 사람이 누른 👎에는 묻지 않습니다. 답변 본문은 저장하지 않습니다. 저장 결과가 불명이라는 안내 뒤 [저장 안 함]을 눌러도 이미 저장된 질문은 취소되지 않으므로 삭제를 요청해 주세요.

답변 생성에 필요한 질문은 Cloudflare Workers AI로 전송됩니다. 이는 원문 저장 동의와 별개이며 [저장 안 함]을 골라도 이미 일어난 전송은 바뀌지 않습니다. 이 기록 기능으로 새 외부 전송은 추가되지 않습니다. Cloudflare 문서(2026-10-16 갱신)는 이 입력·출력을 모델 학습에 쓰지 않고, 일반 요청은 처리 뒤 보관하지 않는다고 밝힙니다. 법적 의무 등 예외와 운영 메타데이터는 남을 수 있습니다.

동의 전 질문과 질문자 식별자는 메모리에만 최대 1시간·500건 대기합니다. DB·파일·운영 로그에 쓰지 않으며, 오래된 것부터 버리고 재시작하면 사라집니다.

원문 저장 동의·거절과 별개로, 기록 기능이 켜지면 “나만 보기”와 실패·시간 초과·비밀값 차단·대기열 가득 결과도 메타데이터 기록 대상입니다. 시각·상태·지연·사용량·근거 식별자와 질문자·평가자의 원본 Discord 식별자를 남깁니다. 본문은 포함하지 않으며, 원본 Discord 식별자는 보존 기간 없이 삭제 요청으로 지웁니다. 서명 오류·허용 범위 밖·미지원 요청·중복 재전송은 제외합니다. 중계가 서비스에 닿지 못한 요청도 질의 기록에는 없고 중계 로그 건수로 따로 셉니다.

질문 원문은 Phase 2 완료 리뷰까지, 늦어도 시작일로부터 약 1개월인 2026-12-04(UTC)까지 보존합니다. 파일럿 분석 원문 열람자와 운영 담당자는 GitHub 계정 byuntil, tkv00 두 명으로 같으며, 삭제 관리 연결로 열람 범위가 넓어지지 않습니다. 운영 서버 관리 권한이 있는 사람은 기술적으로 원문을 읽을 수 있습니다. 원문을 파일럿 분석에 사용하며 평가 세트로 옮기는 사본은 개인 정보를 지웁니다. 연장하면 새 날짜를 공지합니다. 날짜 경과 시 새 동의를 묻지 않으며, 삭제는 자동이 아니라 담당자가 수행합니다.

삭제·문의는 운영 담당자 <운영 담당자 멘션>에게 Discord DM으로 보내 주세요. 본인 기록 삭제는 현재 운영 DB의 원문·식별자를 대상으로 하며 수치·상태·평가 값은 남습니다. 2026-11-04에 확인한 도구·설정·경로에서는 운영 DB 백업이나 다른 DB 사본을 발견하지 못했습니다. 삭제 명령은 현재 운영 DB만 처리하며, 내보낸 파일과 확인하지 못한 사본은 별도입니다. 메모리 대기 처리와 사본 삭제 범위 등 자세한 절차는 Confluence 문서를 확인해 주세요.
